# GHS hazard pictogram combinations

Each file `ghs-<digits>.png` shows the pictograms whose numbers are in the file name, in order:
1 = GHS01 exploding bomb, 2 = GHS02 flame, 3 = GHS03 flame over circle, 4 = GHS04 gas cylinder,
5 = GHS05 corrosion, 6 = GHS06 skull and crossbones, 7 = GHS07 exclamation mark,
8 = GHS08 health hazard, 9 = GHS09 environment.

Example: `ghs-268.png` = flame + skull and crossbones + health hazard.

Source artwork: UNECE GHS pictograms, https://unece.org/transport/dangerous-goods/ghs-pictograms
